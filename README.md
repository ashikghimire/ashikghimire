## ✈️ Civil Aviation Digital Systems — Civil Aviation Authority of Nepal (CAAN)

As web developer & network/server administrator at CAAN, I design, build, and maintain the digital core behind Nepal's civil aviation infrastructure — owning everything from application code to network architecture.

### 🏢 Centralized Multi-Tenant Aviation Engine & CMS

*A sovereign, shared-infrastructure platform (Django + React) hosting, managing, and standardizing 24 government and aviation web portals through a single backend cluster.*

* **Airports Information System ([airports.caanepal.gov.np](https://airports.caanepal.gov.np)):** Centralized digital hub managing public notices, technical airfield data, regulatory publications, and operations for hub airports nationwide.
* **Flight Safety Standards Portal ([flightsafety.caanepal.gov.np](https://flightsafety.caanepal.gov.np)):** Regulatory management platform powering confidential incident reporting, compliance checklists, safety advisories, and risk assessment distribution.
* **Civil Aviation Academy ([academy.caanepal.gov.np](https://academy.caanepal.gov.np)):** Enterprise LMS managing course schedules, aviation certification archives, training registration workflows, and academic publications.
* **International Aerodromes:** Unified CMS nodes for ✈️ **Pokhara International Airport (PIA)** and ✈️ **Gautam Buddha International Airport (GBIA)**.
* **24 Tenant Websites in Production:** International airports, domestic airports (e.g. Simara, Biratnagar, Dhangadhi), training centers, head office, flight safety, and departmental sites — one Django/IIS + Apache/Linux backend cluster with MySQL, purely API-driven React frontend.
* **Platform Capabilities:** Hierarchical PDF document management with full-text search, feedback/resolution tracking with automated email notifications, branded QR code generation with PDF export, server-to-server FIDS (flight data) proxy integration, and strict file-upload security validation.
* **Governance:** RBAC across sadmin, admin, and airport/feedback admin tiers, with full architecture and provisioning handover documentation produced for the platform.

### 📝 Nationwide Feedback & Grievance Management System

* **50+ Connected Offices:** Serving all domestic and international airports, regional hubs, and administrative directorates via one data pipeline.
* **Dual Entry Points:** QR-code and website-based submission channels routed into a single airport office workflow.
* **Intelligent Ticket Routing:** Automated email notifications and forwarding across airport offices, with immutable audit logs and resolution-time analytics.

### 🔌 API Gateway, Network & AI Infrastructure

* **Enterprise API Gateway:** Secure, tokenized gateway managing external system handshakes, flight schedules, and shared state across departments.
* **Public IP Addressing Plan:** Architected CAAN's APNIC-allocated Provider-Independent IP space across core infrastructure and airport branch sites.
* **GPU/AI Infrastructure Planning:** Authored a GPU server specification and RFP-ready procurement document for CAAN's future AI/ML and LLM workloads, with tiered cost modeling.
* **Legacy Systems:** Maintain a dual-node, high-availability OctoberCMS deployment with MySQL replication.

### 📄 DDMS — Government Document Management

A darta/chalani/tipani (registration/dispatch/file-note) system for CAAN, with fiscal-year-scoped numbering, per-office letter templates, and full inter-office workflow tracking.
